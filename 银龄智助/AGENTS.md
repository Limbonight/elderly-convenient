# 老年友好型线上挂号系统（一键挂号适老版）

## 产品定位

面向 60-80 岁老年人的极简线上挂号系统，通过大字体、高对比度、全程语音引导和防诈骗机制，将挂号流程压缩到 3 步以内。

## 设计方向

- 自定义：适老化极简设计
  - 配色：纯白背景 `#FFFFFF` + 纯黑文字 `#000000`（对比度 ≥ 7:1，符合 WCAG AA+）
  - 强调色：医疗蓝 `#1A73E8`（主按钮）、警示红 `#D93025`（防诈警告）、成功绿 `#137333`
  - 字体：正文 ≥ 24px，标题 ≥ 32px，超大字号体系
  - 按钮：高度 ≥ 80px，圆角 16px，字号 ≥ 28px，粗体
  - 间距：大留白，触控区域充分，防误触
  - 零广告、零弹窗、零推荐、零滚动条、零外部链接

## 核心模块

### 老年端（/elder）
- `/elder` 极简首页（3 个大按钮：语音挂号、我的挂号、电话求助）
- `/elder/register` 语音挂号 5 步流程
- `/elder/records` 我的挂号/历史记录
- `/elder/patients` 常用就诊人管理
- `/elder/help` 电话/视频求助

### 子女端（/family）
- `/family` 首页/绑定父母列表
- `/family/bind` 绑定父母信息
- `/family/notifications` 挂号通知
- `/family/assist` 远程协助入口

### 数据看板（/dashboard）
- 挂号完成率、语音使用率、防诈触发次数、平均挂号时长等指标

## 语音能力

- 识别：浏览器 Web Speech API（SpeechRecognition）
- 播报：浏览器 Web Speech API（SpeechSynthesis）
- 语速：≤ 120 字/分钟（rate 0.8-1.0）
- 支持指令：「再说一遍」「返回上一步」「取消挂号」
- 3 次识别失败转人工

## 防诈骗机制

- 敏感词检测（后端）：缴费、转账、验证码、汇款、银行卡、密码
- 命中即触发：红色警告弹窗 + 语音警告 + 通知紧急联系人
- 挂号成功自动播报防诈骗提示
- 外部链接拦截
- 官方认证标识显示

## 数据模型

- users：用户表（老人/子女，带角色区分）
- patients：就诊人表（姓名、身份证、医保卡、关联用户）
- appointments：挂号记录表
- voice_logs：语音识别日志
- fraud_warnings：防诈触发记录
- analytics_events：埋点事件记录
- departments：科室表
- doctors：医生表
- time_slots：号源时间表
